# Arte de escenario en Aseprite

Radio: frente de 64×32, tres capas (madera, rejilla/sintonizador, detalles). Mantiene cuerpo, perillas y antena 3D. Exportar con Aseprite batch usando tools/crear_radio_aseprite.lua y --script-param root=<ruta>. El script conserva el editable y reexporta el PNG.

Vista real: Godot --path . --script res://tests/ver_radio_aseprite.gd -- --prueba-arte. Captura capturas/radio_aseprite_ajustes.png. Desde la cámara actual la gata tapa parte del frente, por lo que el detalle es discreto; no se cambió la cámara ni la posición de la gata para justificar el dibujo.
